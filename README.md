Markov chain bot called MarkovBot [euphoria.leet.nu](https://euphoria.leet.nu/room/xkcd)
a great chat room!

## More functions?

It is also a:
- ai connector to euphoria (with mistral ai key)
- **alternative frontend** to euphoria
- local history of euphoria

## Works?
**yes** with the web app.

# Web app [here!](https://peterforeverGIT.github.io/MBE/webapp/)

## Setup

### Path A:

Download the html file and run from your computer's file.

### Path B:

You have to install an extension like [SimpleModifyHeaders](https://github.com/didierfred/SimpleModifyHeaders) for it to work. (there is also an easier to use ModHeaders extension but that has a possibility of being malware)

Modify the "Origin" Header to "null" value for websites that contain "euphoria.leet.nu/" and apply on all requests.

Open webapp
